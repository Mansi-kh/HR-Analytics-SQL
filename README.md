# 👥 HR Analytics — SQL Business Insights

## 📌 Project Overview
Comprehensive SQL analysis of HR data covering employee 
headcount, attrition, salary, performance, and promotion 
tracking using MySQL.

## 🛠️ Tools Used
- MySQL Workbench
- SQL (JOINs, Subqueries, Aggregations, Window Functions)

## 📊 Key Insights
- Overall attrition rate: 16.12%
- Sales department has highest attrition rate
- Employees with bad work-life balance leave 3x more
- Manager roles earn highest average salary
- 185+ employees overdue for promotion (5+ years)

## 🔑 Queries Covered
✅ Headcount & Department Analysis (Q1-Q3)
✅ Attrition Rate & Age Group Analysis (Q4-Q6)
✅ Salary & Income Analysis (Q7-Q9)
✅ Performance & Promotion Tracking (Q10-Q12)
✅ Advanced SQL — Subqueries & Window Functions (Q13-Q15)
